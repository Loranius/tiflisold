# Тема WordPress «EnRay 2026»

Тема з прототипу `enray/` (головна, «Дім», «Бізнес», «Агро») для сайту enray.com.ua.
Ставиться поруч зі старою темою `enray` і нічого в ній не змінює.

## Що в темі

| Файл | Що робить |
|---|---|
| `front-page.php` | Головна (будь-яка сторінка, призначена головною) |
| `page-dim.php`, `page-biznes.php`, `page-agro.php` | Сторінки сценаріїв. WordPress підхоплює їх за slug сторінки: `dim`, `biznes`, `agro` |
| `page-service.php` + `services/*.php` | Шість сторінок послуг за slug: `proiektuvannia`, `budivnytstvo`, `obsluhovuvannia`, `electrical-works`, `systemy-okhorony-ta-bezpeky`, `videosposterezhennia-cctv`. Вміст генерує `enray/tools/build_services.py` (дані послуг там), тож сторінки не залежать від полів старої теми й мають порожній редактор. Рядки й відповіді «уточнити» бачать лише редактори, відвідувачі — ні |
| `page-keysy.php` | Сторінка «Кейси» (slug `keysy`): усі записи сіткою з головним фото |
| `single.php` | Кейс (запис): заголовок, головне фото, текст, галерея прикріплених фото |
| `page.php`, `index.php`, `404.php` | Решта сторінок у новому стилі |
| `cf7/*.txt` | Готові форми Contact Form 7: головна, три сценарії й одна спільна форма послуг (`service.txt`, назву послуги тема підставляє сама) |
| `assets/` | Стилі, скрипти, шрифти (Onest, Golos Text, JetBrains Mono — локально) і реальні фото EnRay |

Налаштування: **Зовнішній вигляд → Налаштувати → EnRay: контакти й форми**
(телефон, email, адреса, години роботи, ID форм). Меню: **Зовнішній вигляд → Меню**,
місця «Основне меню» і «Меню у футері». Поки меню не призначене, тема показує стандартні пункти.

Yoast SEO лишається головним для title/description. Якщо його немає, тема сама виводить
description для головної й сценаріїв. На головній тема додає розмітку LocalBusiness.

## Встановлення (спершу на копії сайту)

1. Зробіть копію сайту (staging) або повну резервну копію.
2. Завантажте `enray-2026.zip`: **Зовнішній вигляд → Теми → Додати → Завантажити тему**. Поки не активуйте.
3. Створіть сторінки з slug `dim`, `biznes`, `agro` (назви «Для дому», «Для бізнесу», «Агро»). Вміст можна лишити порожнім, розмітку дає тема.
4. Створіть 5 форм Contact Form 7 за файлами `cf7/home.txt`, `cf7/dim.txt`, `cf7/biznes.txt`, `cf7/agro.txt`, `cf7/service.txt`; у вкладці Mail вкажіть адресу, куди йдуть заявки.
5. Активуйте тему, у Налаштуваннях впишіть ID форм і контакти.
6. Пройдіть сторінки: головна, три сценарії, «Кейси», кожен кейс, «Про нас», «Контакти», послуги, «Публічна оферта», «Політика конфіденційності». Надішліть тестову заявку з кожної форми.

## Що перевірити обов'язково

Стара тема `enray` будує частину сторінок власними шаблонами: `page-home.php`, `page-cases.php`,
`page-designing.php`, шаблон кейсу `single-case.php` тощо. Якщо текст, характеристики й галереї там
беруться з полів шаблону (наприклад ACF), а не з редактора, то після перемикання на нову тему ці
сторінки покажуть лише те, що є в редакторі. На копії сайту перевірте:

- «Про нас», «Контакти» (сторінки послуг тема вже рендерить сама, їм поля старої теми не потрібні);
- кейси: чи є в записах текст і характеристики, чи призначене головне фото (сітка «Кейси» показує саме його).

Що вийде порожнім, треба перенести в редактор сторінки або дати доступ до полів, щоб тема їх читала.

## Тестування

Тему перевірено в WordPress Playground (WordPress latest, PHP 8.3, Contact Form 7): усі сторінки
відкриваються без помилок PHP, форми валідують поля, калькулятори заповнюють поля заявки,
горизонтальної прокрутки немає на 1440 і 390 px. Надсилання пошти в Playground не налаштоване,
тож доставку листів треба перевірити на копії сайту.

## Сторінки послуг: як заповнити прогалини

Дані шести послуг — у `enray/tools/build_services.py` (словник `SERVICES`). Значення `TODO`
(None) — те, що має підтвердити компанія: ціни, строки, гарантії, відповіді на окремі питання.
У прототипі вони видні як помаранчеві позначки «уточнити», у темі — лише редакторам.
Впишіть значення замість `TODO`, запустіть `python3 enray/tools/build_services.py` з кореня
репозиторію й перезберіть архів теми. Для електромонтажу й безпеки додайте в `photos` 3–4 власні фото.
