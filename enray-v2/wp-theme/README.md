# Тема WordPress «EnRay 2026 v2»

Нова редакція сайту EnRay (стиль — `enray-v2/DESIGN.md`): реальне фото станції на першому екрані, скляне меню, фотокартки зі скосом пластини знака, шлях сонця й енергетичний градієнт.

Тему повністю генерує `enray-v2/tools/build_wp.py` з прототипу `enray-v2/` (головна, «Для дому», «Для бізнесу» (разом з агрокомпаніями), шість послуг). Правте прототип або дані, потім запускайте з кореня репозиторію:

```
python3 enray-v2/tools/build_pages.py   # сторінки прототипу
python3 enray-v2/tools/build_wp.py      # тема
```

Налаштування, меню, Contact Form 7, JSON-LD, звичайні сторінки, кейси й 404 — ті самі, що в першій темі `enray-2026` (див. `enray/wp-theme/README.md`); обидві теми можна тримати на сайті й перемикати.

## Що в темі
| Файл | Що робить |
|---|---|
| `front-page.php` | Головна |
| `page-dim.php`, `page-biznes.php` | Сторінки рішень, за slug `dim`, `biznes` |
| `page-service.php` + `services/*.php` | Шість послуг за slug: `proiektuvannia`, `budivnytstvo`, `obsluhovuvannia`, `electrical-works`, `systemy-okhorony-ta-bezpeky`, `videosposterezhennia-cctv`. Редактор сторінки може лишатися порожнім. Прогалини «уточнити» (ціни, строки, гарантії, частина відповідей, фото робіт) бачать лише редактори |
| `page-keysy.php`, `single.php`, `page.php`, `index.php`, `404.php` | Кейси й звичайні сторінки у стилі v2 |
| `cf7/*.txt` | Форми Contact Form 7: головна, два рішення, послуги (одна на всі) |
| `assets/` | Стилі v2 (`v2.css`, `page.css`, `wp.css`), скрипти, змінні шрифти, власні фото EnRay |

## Встановлення (спершу на копії сайту)
1. Завантажте `enray-2026-v2.zip`: Зовнішній вигляд → Теми → Додати → Завантажити тему.
2. Сторінки зі slug `dim`, `biznes` і шість сторінок послуг мають існувати (вміст може бути порожнім).
3. Створіть 4 форми Contact Form 7 за `cf7/*.txt` і вкажіть їхні ID: Зовнішній вигляд → Налаштувати → EnRay: контакти й форми. Поки ID немає, замість форми показуються телефон і Viber.
4. Активуйте тему й пройдіть усі сторінки, надішліть тестову заявку з кожної форми.

Перевірено в WordPress Playground (WP 6.x, без Contact Form 7): усі сторінки відкриваються без помилок PHP, калькулятори працюють, axe-core без порушень. Відправку форм CF7 ще треба перевірити на копії сайту.

**Оновлення 2.2.0:** напрямок «Для поливу» прибрано, агрокомпанії входять у «Для бізнесу». Якщо на сайті вже є сторінка `agro`, переведіть її в чернетку й налаштуйте переадресацію `/agro/` → `/biznes/` (наприклад, плагіном Redirection).
